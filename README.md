## Autora 

Yasmin Arantes

## Orientador

Dr. Fabrício Galende Marques de Carvalho

## Tema

Sistema web para execução automática de casos de teste para sistemas da área militar.

## Objetivo

Utilizar uma interface web em conjunto com ferramentas tais como
o selenium webdriver para automatizar diversas categorias de teste para sistemas militares.

## Alguns dos testes a serem automatizados são: 

Teste de navegabilidade;
Teste de segurança;
Teste de funcionalidade (serviço);
Teste de confiabilidade.
